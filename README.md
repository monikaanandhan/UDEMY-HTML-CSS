# UDEMY-HTML-CSS
This is a static Udemy clone project built using only HTML and CSS.
The main purpose of this project was to practice website layout design, responsive styling, and UI development without using any JavaScript or frameworks.

🔹 Features:

Homepage design inspired by Udemy

Navigation bar with logo, search bar, and menu options

Course cards section showcasing sample courses

Responsive layout using CSS Flexbox/Grid

Footer with udemy sights

🔹 Tech Stack:

HTML5 – for structure

CSS3 – for styling and responsiveness

🔹 Learning Outcome:

Through this project, I improved my skills in HTML structuring, CSS Flexbox/Grid, responsive design, and replicating real-world website layouts.
